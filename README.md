Inverted Search Using Hashing in C
Project Description
This project implements an Inverted Search System using Hashing and Linked Lists in C. It indexes words from multiple text files and stores information about the files in which each word appears along with its occurrence count, enabling efficient word searching and retrieval.

Features
Create Database
Display Database
Search Database
Save Database
Update Database
Menu-Driven Interface
Compilation
gcc *.c
Execution
*/a.out f1.txt f2.txt

## Concepts Used

- Hashing
* Linked Lists
- File Handling
- Dynamic Memory Allocation
- Searching
